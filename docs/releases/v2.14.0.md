# v2.14.0

Done
- Mark a video as done. Tap the tick in Pick up where you left off, swipe a library row to the right, or use the ⋮ menu. Each one can be undone.
- A video you watch to the end is marked done by itself.
- A done video leaves Pick up where you left off and the queue, and its picture dims in the library.
- Hide done in the library hides them all.

Home
- Pick up where you left off is now one list of three, with the newest first. See all has the rest.
- Each row shows how far along you are and how much is left.

Look
- Panels are easier to see on OLED black.
- Messages at the bottom of the screen now match your theme.
- In the Light theme, the clock at the top is dark and easy to read.
