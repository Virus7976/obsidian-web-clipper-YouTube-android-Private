## ObsiTube 2.15.3

- Every box now offers the values that property already has in your vault, most used first.
- Tags, categories, authors and any other list or text property work the same way.
- Tap a box to see them, or type to narrow them down.
- The save screen is tighter. Video data is now a small icon inside each box.

Your vault is read again once after this update, so the values can take a moment to show.
