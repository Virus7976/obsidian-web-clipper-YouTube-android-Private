# 2.2.0

- The search box is a slim, one line pill now. It no longer wraps or glows.
- Tap and hold any video, in the Library, Feed, Queue, a playlist or a channel, to open its menu: play next, add to queue, save audio, tags and more.
- The Library sections match. Playlists, Pick up where you left off and Pinned use the same card size and the same header. Each has See all, which opens that section on its own page.
- Channel pages now have the Options and Queue buttons too.
