# 2.1.0

**Library**
- Pinned videos are now a row you swipe sideways. Tap See all to open every pinned video on its own page.
- Pinned videos no longer repeat in the main list.

**Search everywhere**
- Every tab has a search box: Library, Feed, Queue, each playlist, and each channel.
- The library search also looks inside your highlights and notes.
- On a channel page, searching keeps loading the rest of the channel, so it finds old videos too.

**Feed**
- The feed now looks like GrayJay: your channels in a wide row on top, filters (All, New, In library), and a tight list with a wide picture.
- Each row has Options and a Queue button. A bar on the picture shows how far you got.
