- Clip now uses the vault you chose in Settings. Before, a vault name stored inside an imported Web Clipper template could win.
- Imported templates no longer add their vault names to your vault list, and a clip never adds one. Vault names that older versions added by mistake are removed once, on first start. Vaults with a folder, and the one you selected, stay.
- Clipping again only brings back the last vault if it is one of your vaults.

Not tested on a phone by the author.
