# v2.9.0

**Tags and note links on each highlight**
- The note bar under a highlight has two new buttons: a tag and a link.
- **Tags:** tap the tag button, type a tag, press done. Tags you used before, and the tags in your vault, show up as taps. Tags are saved with the highlight and written into your Obsidian note as `#tags` after the note.
- **Link a note:** tap the link button, or type `[[` in the note. The note picker opens over your vault. Pick one and it becomes `[[Note name]]`, like Obsidian.
- Both work in search. `#tag` finds highlights with that tag. The Highlights screen has tag chips and shows each card's tags. `[[links]]` show in the accent colour.

**Cleaner**
- Highlights and Review are now one card on the Library page: "Highlights, 67 saved", with a Review button when some are due. The loose chip is gone.
- Feed rows: the loose "Options" and queue pills under each title are gone. Each row has one three-dot button at the end, like every other list. Hold still opens the same menu.
